## 常见问题

### Q：普通玩家可以创建兑换码吗？

A：不能。兑换、帮助命令默认开放；创建、查看列表、删除、清理和重载需要 `giftcode.admin`，该权限默认只授予 OP。需要使用权限插件分配时，请同时保留玩家的 `giftcode.use` 权限。

### Q：为什么控制台不能兑换或使用 `/gc hand`？

A：这两个操作需要玩家身份。控制台可以执行 `create`、`list`、`clear`、`delete` 和 `reload` 等管理命令。

### Q：`/gc hand` 会保留物品的附魔和自定义数据吗？

A：会。手持物品会保存为包含完整 NBT 的兑换奖励；普通 `item` 类型只按 Material ID 和数量发放。

### Q：修改 `config.yml` 后没有生效怎么办？

A：确认文件中的 `language` 值为 `zh_cn` 或 `en_us`，然后执行 `/gc reload`。如果语言文件不存在，插件会自动回退到 `zh_cn.yml`。

### Q：兑换码数据存在哪里？

A：数据存储在 `plugins/GiftCode/data.db` 的 SQLite 文件中。不要在服务器运行时手动编辑该文件；迁移时停止服务器后整体复制即可。

## 遇到无法解决的报错

1. 先确认服务器核心、Minecraft 版本和 GiftCode 版本满足环境要求。
2. 更新到最新版本后再次复现，并记录完整的控制台报错。
3. 前往 [GitHub Issues](https://github.com/wunanc/GiftCode/issues) 提交问题，附上复现步骤、服务器核心版本、插件版本和日志。
4. 也可以加入 [QQ 群](https://qm.qq.com/q/OQ33f3SHeg) 讨论。

提交日志时请隐藏服务器地址、数据库内容和其他敏感信息。
