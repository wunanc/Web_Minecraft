## 基本信息

主命令是 `/gc`，别名为 `/giftcode`。兑换码由插件生成 UUID，创建成功后可以在聊天框中点击复制。

| 指令 | 说明 | 权限节点 |
|:-----|:-----|:---------|
| `/gc <兑换码 UUID>` | 兑换礼包码 | `giftcode.use`（默认所有玩家） |
| `/gc help` | 查看帮助菜单 | 无额外权限 |
| `/gc create <cmd\|item> <次数> <过期秒数> <内容...>` | 创建命令或普通物品兑换码 | `giftcode.admin` |
| `/gc hand <次数> <过期秒数>` | 将主手物品（含 NBT）制作成兑换码 | `giftcode.admin` |
| `/gc list [页码]` | 分页查看兑换码 | `giftcode.admin` |
| `/gc delete <兑换码 UUID>` | 删除指定兑换码 | `giftcode.admin` |
| `/gc clear` | 清理已过期或已用完的兑换码 | `giftcode.admin` |
| `/gc reload` | 重载配置和语言文件 | `giftcode.admin` |

`<过期秒数>` 从创建时开始计算；填写 `-1` 表示永久有效。`<次数>` 是该兑换码可被兑换的总次数，而不是每名玩家的次数。

## 创建命令奖励

```text
/gc create cmd 10 86400 eco give %player% 1000
```

兑换后，插件会以控制台身份执行命令，并把 `%player%` 替换为兑换者的玩家名。命令内容中的空格会被保留。

## 创建普通物品奖励

```text
/gc create item 5 -1 DIAMOND 3
```

这会创建一个永久有效、总共可兑换 5 次、每次发放 3 个钻石的兑换码。物品名称使用 Bukkit/Paper 的 `Material` ID。

## 创建手持物品奖励

```text
/gc hand 1 604800
```

主手物品会以 Base64 形式保存，包含自定义名称、附魔和其他 NBT 数据。兑换时如果背包没有空间，多出的物品会掉落在玩家当前位置。

## 管理兑换码

`/gc list` 每页显示 10 条记录；列表中的 UUID 可以点击复制。兑换码过期或次数耗尽后不会自动从数据库删除，可以使用 `/gc clear` 进行清理。`/gc reload` 只重载配置和语言文件，不会删除兑换码数据。
