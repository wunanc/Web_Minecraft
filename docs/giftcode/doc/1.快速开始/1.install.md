## 环境要求

GiftCode 插件运行所需的环境：

- `Java 17` 或更高版本；
- `Paper/Folia` `1.20.1` 或更高版本；
- 插件在 `plugin.yml` 中声明支持 Folia。

::: warning
GiftCode 主要针对 Paper/Folia 进行测试，其他 Bukkit/Spigot 核心或旧版本不保证可以稳定运行。
:::

## 安装

1. 下载最新版本的 `GiftCode-x.x.x.jar`。
2. 将文件放入服务器的 `plugins` 文件夹。
3. 重启服务器。插件会自动生成默认配置和语言文件，并创建 SQLite 数据库。
4. 根据需要修改 `plugins/GiftCode/config.yml`，然后执行 `/gc reload`。

首次启动后，兑换码数据保存在 `plugins/GiftCode/data.db`。迁移或更新服务器前请一并备份这个文件。

## 更新

更新时直接替换插件 `.jar` 并重启服务器即可。插件会保留已有的 `data.db`，无需重新创建兑换码。
