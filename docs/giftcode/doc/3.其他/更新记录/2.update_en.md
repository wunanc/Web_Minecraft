## Version 2.0.0 (2026-03-25)

The current public release is `v2.0.0`, supporting:

- Paper/Folia 1.20.1+ with Java 17+;
- item, full-NBT hand-item, and console-command rewards;
- global usage limits, expiration times, paginated lists, manual deletion, and invalid-code cleanup;
- asynchronous SQLite storage;
- Chinese/English language files with MiniMessage formatting;
- downloads through GitHub Releases, Modrinth, and Spigot.

See [GitHub Releases](https://github.com/wunanc/GiftCode/releases) for the complete changelog.
