## 版本 2.0.0（2026-03-25）

当前公开版本为 `v2.0.0`，支持：

- Paper/Folia 1.20.1+ 与 Java 17+；
- 普通物品、手持 NBT 物品和控制台命令三类奖励；
- 总兑换次数、过期时间、列表分页、手动删除和失效码清理；
- SQLite 异步数据存储；
- 中文/英文语言文件与 MiniMessage 消息格式；
- GitHub Releases、Modrinth 和 Spigot 下载渠道。

完整变更请查看 [GitHub Releases](https://github.com/wunanc/GiftCode/releases)。
