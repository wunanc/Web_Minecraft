## 当前公开入口

`GiftCode` 主类目前公开了 `getLang()`，可以获取插件的语言管理器。该入口不是独立 API 模块，升级前请在目标版本源码中确认签名。

```java
GiftCode giftCode = JavaPlugin.getPlugin(GiftCode.class);
giftCode.getLang().send(sender, "help_header");
```

语言管理器会读取插件当前选择的语言文件，并使用 MiniMessage 解析消息。自定义消息键需要同时加入 `plugins/GiftCode/lang/zh_cn.yml` 和 `en_us.yml`，再执行 `/gc reload`。

如果需要更深度的兑换码创建、查询或兑换集成，请通过 [GitHub Issues](https://github.com/wunanc/GiftCode/issues) 说明使用场景，避免直接依赖内部数据库结构。
